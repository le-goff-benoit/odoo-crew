La classe Constraint(TableObject) documente une contrainte SQL de table, ajoutée par ADD CONSTRAINT. Exemple officiel de définition : CHECK (x > 0).
Extrait court : `The definition of the constraint is used to ADD CONSTRAINT on the table.`
Ce constat source ne prouve pas qu'un module ou sa contrainte est installé sur une base client.
