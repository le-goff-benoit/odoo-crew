# Organisation de l'épreuve E03-D

Exécution par un seul agent : analyse courte, tests rouges, correctif, tests verts, inventaire et consolidation. Aucune délégation : le delta est une contrainte et les vérifications dépendent du même état de module et de la même copie. Aucun enfant créé, aucun enfant restant à joindre.

Un seul écrivain du module et un seul utilisateur du clone : Codex développeur/QA E03-D. Seuls le module autorisé et output/ ont été écrits directement ; le runtime fourni a produit ses preuves dans runtime-evidence/. Aucun flow de livraison créé. Aucun appel CLI de modèle, autre cas ou oracle consulté.

Les mémoires proposées sont des remplacements complets. Les mémoires initiales restent inchangées ; le journal initial est préfixe exact du journal proposé, vérifié en bytes ; ajout inférieur à 15 lignes.
