Le module fourni bloque déjà les quantités négatives et conserve les lignes à zéro. Aucun développement supplémentaire n’est justifié : il ferait doublon.

Le contrôle est prévu pour couvrir aussi les imports. Cette conclusion vient de la lecture du code. Elle ne confirme pas son installation chez un client ; aucun essai sur une base n’a été réalisé.

Si une validation de l’installation réelle est nécessaire, le responsable technique vérifiera le module sur une copie locale. La QA contrôlera ensuite la saisie et les imports. Les prix à zéro restent autorisés, y compris sur les lignes confirmées. Le bouton déjà accepté reste inchangé.
