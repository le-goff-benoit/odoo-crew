Il reste à décider du sort des 42 commandes brouillon sans référence client : devront-elles être complétées avant confirmation, ou bénéficieront-elles d’une exception ? Aucune commande déjà confirmée n’est concernée.

Je recommande de leur appliquer la règle uniforme : les commerciaux devront renseigner leur référence avant de les confirmer. Les exempter éviterait cette reprise immédiate, mais laisserait une exception durable à maintenir alors que les nouvelles commandes seraient bloquées. Aucune contrainte commerciale connue ne justifie cette exception à ce stade.

Pendant cet arbitrage, le développeur peut préparer les tests indépendants sur la copie, dans le cadre du travail déjà autorisé.
