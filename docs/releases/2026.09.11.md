# Odoo Crew — 11 septembre 2026

Cette version accompagne [Odoo Tricorder 0.2.7](https://github.com/le-goff-benoit/odoo-tricorder/releases/tag/v0.2.7).

- Nouveaux chronomètres : veille Linux exclue automatiquement, reprise après
  fermeture de fenêtre, redémarrage signalé sans inventer une durée.
- Aperçu des chronomètres en cours, sans écriture du registre par le cockpit.
- Compteurs Claude/Codex conservés champ par champ : cache inconnu ne masque
  plus les entrées/sorties connues ; aucune extrapolation des coûts.
- Lecture des journaux natifs pendant leur écriture sans perdre le préfixe valide.
- Contrôle des chronomètres ouverts avant nouvelle clôture et répartition des
  passages par rôle. Les anciens bilans restent vérifiables sans migration.
- Fonctionnalité d’envoi email retirée ; compatibilité inerte avec les anciennes
  fenêtres Tricorder. Aucun accès aux brouillons ni au trousseau.

## Mise à jour

Depuis le dossier d’installation d’Odoo Crew :

```bash
git pull --ff-only
./build.sh
```

Pour une première installation, suivre le [guide](https://github.com/le-goff-benoit/odoo-crew/blob/v2026.09.11/docs/INSTALL.md).
Le générateur vérifie les tests et la parité Claude/Codex.

## Vérification et limites

271 tests déterministes passent, avec validation du graphe et génération isolée
puis active. Les suspensions sont simulées : pas de mise en veille physique du
poste. Les durées natives sans trace de suspension et les anciennes mesures ne
sont pas réécrites. Les attentes hors veille restent incluses.

Limite connue : les profils sont encore réécrits directement par `build.sh`.
Un agent qui les recharge pendant la génération peut signaler temporairement
un en-tête incomplet ; la vérification finale confirme les fichiers complets.
