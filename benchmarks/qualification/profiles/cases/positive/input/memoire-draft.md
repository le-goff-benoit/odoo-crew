# Mémoire proposée
La tâche indépendante T04 a confirmé que les exports de la société B conservent leur fuseau Europe/Zurich. Cette décision publiée reste applicable.
La pénalité de location de la société A est reçue sur copie locale à 2 CHF par jour dès le septième jour inclus ; le sixième jour vaut zéro. Les prêts, y compris prolongés, restent exclus. Le comportement de la société B est conservé. Les cinq observations sont conformes ; aucun déploiement ni migration distante n'a été réalisé ou vérifié.
