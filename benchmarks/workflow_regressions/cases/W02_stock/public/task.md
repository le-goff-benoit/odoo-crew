# Préparation, correction, reliquat et cron

Odoo 19.0 : une préparation préremplit 5 unités. Le magasinier corrige à 2, valide avec reliquat, puis le cron prépare les 3 restantes. Le cron ne doit ni remettre 5 ni modifier la livraison terminée. Exécuter sous un magasinier ordinaire ; un utilisateur portail ne doit pas pouvoir préparer.
